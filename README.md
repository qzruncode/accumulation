## 笔记约定

- 先解释解决什么问题，再说明原理和关键参数。
- 说明适用场景与边界，避免把单一实现当成通用结论。
- 涉及具体框架或服务时，尽量附官方文档或原始资料链接。
- 面向工程实践，记录验证方法和容易踩的坑。
